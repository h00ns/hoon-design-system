# hoon-design-system

접근성과 사용성을 기본값으로 갖춘 React 디자인 시스템입니다.

## 패키지

| 패키지            | 역할                                                 |
| ----------------- | ---------------------------------------------------- |
| `@hoon-ds/tokens` | 디자인 토큰 → CSS 변수 · JS · JSON (프레임워크 무관) |
| `@hoon-ds/css`    | 컴포넌트 스타일 (순수 CSS, cascade layer)            |
| `@hoon-ds/react`  | Radix 기반 React 컴포넌트                            |

## 시작하기

```tsx
import '@hoon-ds/tokens/css';
import '@hoon-ds/css';
import { Button } from '@hoon-ds/react';

<Button onClick={save}>저장</Button>;
```

## 원칙

- **키보드만으로 모든 기능을 쓸 수 있다.** 포커스는 항상 보이고, 예측 가능한 곳으로 이동한다.
- **스크린리더가 이해할 수 있다.** 역할·이름·상태를 WAI-ARIA APG 패턴대로 노출한다.
- **사용자 설정을 존중한다.** 다크 모드, 동작 줄이기, 고대비 모드, 글꼴 확대(200%)에서도 깨지지 않는다.
- **색 대비는 테스트로 보장한다.** 토큰 대비가 WCAG AA 에 못 미치면 빌드가 실패한다.

상단 툴바에서 테마를 바꿔볼 수 있고, 각 스토리의 **Accessibility** 패널에서 axe 검사 결과를 확인할 수 있습니다.
