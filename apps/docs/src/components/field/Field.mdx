# Field

폼 컨트롤에 **레이블·설명·오류 메시지**를 붙이고, 접근성 연결(`for`·`aria-describedby`·`aria-invalid`·`required`)을 자동으로 처리한다.
Input, Textarea, Checkbox, RadioGroup, Switch 가 Field 안에 있으면 별도 설정 없이 연결된다.

<Canvas of={FieldStories.Playground} />
<Controls of={FieldStories.Playground} />

## 사용법

```tsx
import { Field, Input } from '@hoon-ds/react';

<Field.Root invalid={!!error} required>
  <Field.Label>이메일</Field.Label>
  <Input type="email" />
  <Field.Description>로그인에 사용됩니다.</Field.Description>
  <Field.ErrorMessage>{error}</Field.ErrorMessage>
</Field.Root>;
```

| 부품                 | 역할                                                                                   |
| -------------------- | -------------------------------------------------------------------------------------- |
| `Field.Root`         | `invalid`·`required`·`disabled` 상태를 안쪽 컨트롤에 전달한다                          |
| `Field.Label`        | 컨트롤의 레이블. `required` 면 `*` 를 붙인다 (시각용, 스크린리더는 `required` 로 읽음) |
| `Field.Description`  | 보조 설명. 컨트롤에 `aria-describedby` 로 연결                                         |
| `Field.ErrorMessage` | 오류 메시지. `invalid` 일 때만 렌더링·연결된다 (`forceMount` 로 항상 렌더링)           |

컨트롤이 직접 받은 `id`·`disabled`·`required`·`aria-describedby` 는 Field 값보다 우선하고, `aria-describedby` 는 합쳐진다.

### 여러 컨트롤

RadioGroup 처럼 `<label for>` 로 연결할 수 없는 그룹은 `aria-labelledby` 로 레이블이 연결된다.

### 폼 검증

제출할 때 검증하고 **첫 번째 오류 필드로 포커스를 옮긴다.** 스크린리더는 레이블, 오류 상태, 오류 메시지를 함께 읽는다.

## 접근성

### 키보드

Field 자체는 포커스를 받지 않는다. `Field.Label` 을 누르면 연결된 컨트롤로 포커스가 이동한다(체크박스·스위치는 토글).

### 스크린리더

- 레이블: `<label for>` (그룹 컨트롤은 `aria-labelledby`)
- 설명·오류: `aria-describedby` — 설명 다음에 오류 순서로 읽는다.
- 오류 상태: `aria-invalid="true"` — 오류가 사라지면 연결도 함께 끊긴다.
- 필수: 네이티브 `required` 또는 `aria-required`. `*` 기호는 `aria-hidden`.
- 오류 메시지는 live region 이 아니다. 입력할 때마다 읽히면 방해가 되므로, 제출 시 오류 필드로 **포커스를 옮겨** 알린다.

### 사용자 설정

- 오류는 빨간색 + 아이콘 + 텍스트로 전달한다 (WCAG 1.4.1).
- 한글 줄바꿈은 단어 단위로 끊긴다(`word-break: keep-all`, base.css).
