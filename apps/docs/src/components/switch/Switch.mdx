# Switch

켜고 끄는 **즉시 반영**되는 설정. 알림 받기, 다크 모드, 자동 저장처럼 누르는 순간 효과가 생길 때 쓴다.

<Canvas of={SwitchStories.Playground} />
<Controls of={SwitchStories.Playground} />

## 사용법

```tsx
import { Switch } from '@hoon-ds/react';

<Switch checked={enabled} onCheckedChange={setEnabled}>
  알림 받기
</Switch>;
```

`children` 은 `<label>` 로 렌더링된다. `className`·`style` 은 바깥 래퍼에, 나머지 props 와 `ref` 는 `button[role=switch]` 에 전달된다.

### Switch 와 Checkbox

|            | Switch               | Checkbox                      |
| ---------- | -------------------- | ----------------------------- |
| 반영 시점  | 누르는 즉시          | 제출 버튼을 눌렀을 때         |
| 예         | 알림 받기, 다크 모드 | 약관 동의, 필터 선택          |
| 중간 상태  | 없음                 | `indeterminate` 가능          |
| 스크린리더 | "스위치, 켬/끔"      | "체크박스, 선택됨/선택 안 됨" |

## 접근성

### 키보드

| 키                | 동작        |
| ----------------- | ----------- |
| `Tab`             | 포커스 이동 |
| `Space` / `Enter` | 켜기/끄기   |

### 스크린리더

- `role="switch"` + `aria-checked` 로 "켬/끔" 상태를 전달한다.
- 레이블은 `<label for>` 로 연결되어 레이블을 눌러도 토글된다.
- 상태가 바뀌어 생긴 **결과**(예: "저장됨")는 Toast 나 live region 으로 따로 알린다.

### 사용자 설정

- 켜짐/꺼짐은 색뿐 아니라 손잡이 **위치**로 구분된다. 꺼진 트랙도 배경과 3:1 이상 대비라 경계가 보인다.
- `prefers-reduced-motion` 이면 손잡이가 미끄러지지 않고 바로 이동한다.
- 오른쪽에서 왼쪽으로 쓰는 언어(RTL)에서는 손잡이 방향이 뒤집힌다.
- Windows 고대비 모드에서 트랙 테두리와 켜짐 상태가 시스템 색으로 보인다.
