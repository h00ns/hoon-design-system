# Tooltip

요소에 마우스를 올리거나 키보드로 포커스했을 때 **짧은 보조 설명**을 보여준다.
아이콘 버튼의 이름, 단축키, 비활성 이유처럼 _없어도 기능을 쓸 수 있지만 있으면 도움이 되는_ 정보에 쓴다.

<Canvas of={TooltipStories.Playground} />
<Controls of={TooltipStories.Playground} />

> **툴팁은 터치 기기에서 열리지 않고, 화면 확대 사용자는 놓치기 쉽다.**
> 꼭 알아야 하는 정보(오류, 필수 조건, 가격)는 툴팁에 숨기지 말고 화면에 직접 보여준다.

## 사용법

대부분은 한 줄짜리 `SimpleTooltip` 으로 충분하다.

```tsx
import { IconButton, SimpleTooltip } from '@hoon-ds/react';

<SimpleTooltip content="설정">
  <IconButton aria-label="설정">
    <GearIcon />
  </IconButton>
</SimpleTooltip>;
```

세밀하게 조정하려면 조립형 API 를 쓴다.

```tsx
import { Tooltip } from '@hoon-ds/react';

<Tooltip.Root>
  <Tooltip.Trigger asChild>
    <Button>저장</Button>
  </Tooltip.Trigger>
  <Tooltip.Content side="bottom">저장 (⌘S)</Tooltip.Content>
</Tooltip.Root>;
```

| 부품               | 역할                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| `Tooltip.Provider` | 여러 툴팁의 지연 시간 공유. 앱 최상단에 한 번 두는 것을 권장 (없어도 동작) |
| `Tooltip.Root`     | 툴팁 하나의 상태. `open`/`onOpenChange`, `delayDuration`                   |
| `Tooltip.Trigger`  | 툴팁을 띄우는 요소. **포커스 가능한 요소**를 `asChild` 로 감싼다           |
| `Tooltip.Content`  | 툴팁 내용. 포털에 렌더링되고 화살표(`arrow`, 기본 켜짐)를 그린다           |
| `SimpleTooltip`    | 위 네 부품을 합친 축약형. `content` 와 자식 요소 하나만 넘긴다             |

## 예시

### 아이콘 툴바

## 접근성

[WAI-ARIA APG Tooltip 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)과 WCAG 1.4.13(호버·포커스 시 나타나는 콘텐츠)을 따른다.

### 키보드

| 키    | 동작                                           |
| ----- | ---------------------------------------------- |
| `Tab` | 트리거에 포커스가 오면 툴팁이 열린다           |
| `Esc` | 툴팁을 닫는다. 포커스는 트리거에 그대로 남는다 |

### 스크린리더

- 열린 툴팁은 `role="tooltip"` 이고, 트리거의 `aria-describedby` 로 연결되어 **설명**으로 읽힌다 (이름이 아니다).
  그래서 아이콘 버튼은 툴팁과 별개로 반드시 `aria-label` 이 있어야 한다.
- 툴팁에는 포커스가 가지 않는다. 링크·버튼 같은 인터랙티브 요소를 넣으면 키보드로 닿을 수 없으므로 Popover 를 쓴다.

### 사용자 설정

- **dismissible**: Esc 로 닫을 수 있다.
- **hoverable**: 툴팁 위로 마우스를 옮겨도 닫히지 않아 확대 사용자가 내용을 읽을 수 있다.
- **persistent**: 사용자가 포인터·포커스를 옮기거나 Esc 를 누를 때까지 사라지지 않는다.
- 기본 300ms 지연으로 커서가 스쳐 지나갈 때 깜빡이지 않는다. 클릭으로 포커스될 때는 열리지 않는다.
- `prefers-reduced-motion` 이면 이동 없이 페이드만 남는다. Windows 고대비 모드에서는 시스템 색 테두리를 그린다.
- 터치 기기에서는 열리지 않는다 (Radix 의 의도된 동작). 터치 사용자에게도 필요한 정보라면 화면에 보이게 둔다.
