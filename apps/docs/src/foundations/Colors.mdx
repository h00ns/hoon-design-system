# Colors

색상은 두 단계로 나뉜다.

1. **Primitive** — `gray-500`, `blue-600` 처럼 색 자체를 이름으로 가진 팔레트. 테마와 무관하다.
2. **Semantic** — `fg-default`, `accent-solid` 처럼 **역할**을 이름으로 가진 토큰. 테마(light/dark)에 따라 다른 primitive 를 가리킨다.

> 컴포넌트와 화면에서는 **항상 시맨틱 토큰만** 쓴다. primitive 를 직접 쓰면 다크 모드에서 깨진다.

```css
/* ✅ */
color: var(--hds-color-fg-muted);
/* ❌ 다크 모드에서 대비가 무너진다 */
color: var(--hds-color-gray-600);
```

모든 전경/배경 조합의 대비는 `packages/tokens/test/contrast.test.ts` 가 **빌드 때마다 검증한다.** 텍스트 4.5:1, UI 경계·포커스 링 3:1 (WCAG 2.2 AA).

## 의미 색상

각 의미 색은 `solid`(채움), `fg`(텍스트), `subtle`(옅은 배경) 세트로 쓴다. **색만으로 의미를 전달하지 않는다** — 아이콘이나 텍스트를 함께 둔다 (WCAG 1.4.1).
