# 설치

## 1. 패키지 설치

```bash
pnpm add @hoon-ds/react @hoon-ds/css @hoon-ds/tokens
```

`react`, `react-dom` 18.2 이상 또는 19 가 필요하다.

## 2. 스타일 불러오기

앱 진입점에서 **한 번만** 불러온다. 순서가 중요하다.

```tsx
// main.tsx 또는 app/layout.tsx
import '@hoon-ds/tokens/css'; // 1. 디자인 토큰 (CSS 변수) — 필수
import '@hoon-ds/css/base.css'; // 2. 전역 베이스 (box-sizing, 본문 글꼴, 포커스 링) — 선택
import '@hoon-ds/css'; // 3. 컴포넌트 스타일 — 필수
```

`base.css` 는 앱 전체를 이 디자인 시스템으로 그릴 때만 쓴다. 기존 앱에 일부 컴포넌트만 도입한다면 생략해도 컴포넌트는 정상 동작한다.

## 3. 사용

```tsx
import { Button } from '@hoon-ds/react';

export function SaveButton() {
  return <Button onClick={save}>저장</Button>;
}
```

## Next.js (App Router)

`@hoon-ds/react` 는 빌드 결과에 `'use client'` 가 들어 있어 서버 컴포넌트에서 바로 import 할 수 있다.

```tsx
// app/layout.tsx
import '@hoon-ds/tokens/css';
import '@hoon-ds/css/base.css';
import '@hoon-ds/css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="ko">
      <body>{children}</body>
    </html>
  );
}
```

> `<html lang="ko">` 를 꼭 지정한다. 스크린리더가 올바른 발음 규칙으로 읽는다 (WCAG 3.1.1).

## React 없이 쓰기

스타일은 순수 CSS 라서 클래스와 `data-*` 속성만 맞추면 어디서나 쓸 수 있다. 단, 키보드·포커스·ARIA 동작은 직접 구현해야 한다.

```html
<link rel="stylesheet" href="node_modules/@hoon-ds/tokens/dist/css/tokens.css" />
<link rel="stylesheet" href="node_modules/@hoon-ds/css/dist/index.css" />

<button class="hds-button" data-variant="secondary" data-size="md" type="button">취소</button>
```

## 스타일 덮어쓰기

컴포넌트 스타일은 모두 `@layer hds.components` 안에 있다. **레이어 밖에 쓴 CSS 는 선택자 우선순위와 상관없이 항상 이긴다** — `!important` 가 필요 없다.

```css
/* 앱 CSS — 레이어 밖이므로 항상 우선 */
.checkout .hds-button {
  border-radius: var(--hds-radius-full);
}
```

변형별 색은 내부 변수(`--_bg`, `--_fg` …)로 관리하지만, 이건 공개 API 가 아니다. 가능하면 토큰(`--hds-*`)을 바꾸는 방식으로 커스터마이즈한다.
