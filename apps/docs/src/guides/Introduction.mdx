# hoon-design-system

**접근성과 사용성을 기본값으로 갖춘 React 디자인 시스템.**
토큰과 스타일은 프레임워크와 무관한 CSS 로, 동작은 [Radix](https://www.radix-ui.com/) 위에 React 로 만든다.

## 패키지

| 패키지            | 역할                                                 |
| ----------------- | ---------------------------------------------------- |
| `@hoon-ds/tokens` | 디자인 토큰 → CSS 변수 · JS · JSON (light/dark)      |
| `@hoon-ds/css`    | 컴포넌트 스타일 — 순수 CSS, cascade layer            |
| `@hoon-ds/react`  | 접근성을 갖춘 React 컴포넌트 (React 18·19, RSC 호환) |

```tsx
import '@hoon-ds/tokens/css';
import '@hoon-ds/css';
import { Button } from '@hoon-ds/react';

<Button onClick={save}>저장</Button>;
```

자세한 내용은 [설치](?path=/docs/시작하기-설치--docs) 를 본다.

## 원칙

1. **키보드만으로 모든 기능을 쓸 수 있다.** 포커스는 항상 보이고 예측 가능한 곳으로 이동한다.
2. **스크린리더가 이해할 수 있다.** 역할·이름·상태를 WAI-ARIA APG 패턴대로 노출한다.
3. **사용자 설정을 존중한다.** 다크 모드, 동작 줄이기, 고대비, 200% 확대에서도 깨지지 않는다.
4. **색 대비는 테스트로 보장한다.** 토큰 대비가 WCAG AA 에 못 미치면 빌드가 실패한다.
5. **실수하기 어렵게 만든다.** 버튼 기본 `type="button"`, 아이콘 버튼 `aria-label` 필수처럼 잘못된 사용을 API 단계에서 막는다.

## 이 문서 보는 법

- 상단 툴바의 **Theme** 으로 라이트/다크를 바꿔 볼 수 있다.
- 각 스토리 화면 하단의 **Accessibility** 패널에서 axe 검사 결과를 확인할 수 있다.
- 모든 컴포넌트 문서는 같은 순서다: 개요 → 사용법 → 예시 → **접근성**(키보드 · 스크린리더 · 사용자 설정) → 가이드.
