현재 페이지가 **어디에 있는지** 상위 경로와 함께 보여준다. 계층이 깊은 설정, 문서, 상품 분류에서 한 단계씩 올라갈 수 있게 한다.
[WAI-ARIA Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/) 패턴을 따른다.

  <Basic client:idle />
</Preview>

## 사용법

```tsx
import { Breadcrumb } from '@hoon-ds/react';

<Breadcrumb.Root>
  <Breadcrumb.List>
    <Breadcrumb.Item>
      <Breadcrumb.Link href="/">홈</Breadcrumb.Link>
    </Breadcrumb.Item>
    <Breadcrumb.Separator />
    <Breadcrumb.Item>
      <Breadcrumb.Page>현재 페이지</Breadcrumb.Page>
    </Breadcrumb.Item>
  </Breadcrumb.List>
</Breadcrumb.Root>;
```

| 부품                   | 역할                                                   |
| ---------------------- | ------------------------------------------------------ |
| `Breadcrumb.Root`      | `<nav aria-label="현재 위치">`                         |
| `Breadcrumb.List`      | 순서 있는 목록 `<ol>`                                  |
| `Breadcrumb.Item`      | 경로 항목 `<li>`                                       |
| `Breadcrumb.Link`      | 상위 경로 링크. 라우터 링크는 `asChild`                |
| `Breadcrumb.Page`      | 현재 페이지. 링크가 아니며 `aria-current="page"`       |
| `Breadcrumb.Separator` | 구분자. 보조기기에서 숨긴다                            |
| `Breadcrumb.Ellipsis`  | 접힌 경로를 여는 버튼. DropdownMenu 의 Trigger 로 쓴다 |

## 예시

### 경로 접기

경로가 길면 처음과 현재 위치만 남기고 중간을 접는다. `Breadcrumb.Ellipsis` 를 [DropdownMenu](/components/dropdown-menu/) 의 Trigger 로 감싸면 접힌 경로를 메뉴로 열 수 있다.

## 접근성

### 키보드

| 키              | 동작                                     |
| --------------- | ---------------------------------------- |
| `Tab`           | 경로 링크와 접기 버튼 사이를 이동한다    |
| `Enter`         | 링크를 연다. 접기 버튼에서는 메뉴를 연다 |
| `↑` `↓` / `Esc` | 열린 메뉴 안에서 이동하고 닫는다         |

### 스크린리더

- `<nav>` 랜드마크라 랜드마크 목록에서 "현재 위치" 로 바로 찾아갈 수 있다.
- 순서 있는 목록이라 "목록, 3개 항목" 처럼 경로의 깊이를 알려준다. 구분자는 목록 항목 수에 들어가지 않는다.
- 현재 페이지는 `aria-current="page"` 로 "현재 페이지" 라고 읽힌다.
- 접기 버튼의 기본 이름은 "숨겨진 경로 보기" 다.

### 사용자 설정

- Windows 고대비 모드에서 링크가 시스템 링크 색으로, 접기 버튼이 테두리와 함께 보인다.
- 좁은 화면에서는 항목이 줄바꿈된다. 경로가 길면 접기를 쓴다.
