관련된 정보와 동작을 **하나의 표면**으로 묶는다. 요금제, 글 목록, 설정 그룹처럼 내용이 서로 독립적인 덩어리일 때 쓴다.
단순히 영역을 나누기만 한다면 카드 대신 여백이나 [Separator](/components/separator/) 가 덜 시끄럽다.

</Preview>

## 사용법

```tsx
import { Card } from '@hoon-ds/react';

<Card.Root>
  <Card.Header>
    <Card.Title>제목</Card.Title>
    <Card.Description>설명</Card.Description>
  </Card.Header>
  <Card.Body>본문</Card.Body>
  <Card.Footer>버튼</Card.Footer>
</Card.Root>;
```

| 부품               | 역할                                                             |
| ------------------ | ---------------------------------------------------------------- |
| `Card.Root`        | 표면. `variant`, `padding`, `interactive`, `asChild`             |
| `Card.Header`      | 제목과 설명 묶음                                                 |
| `Card.Title`       | 제목. 기본 `<h3>`, 페이지 제목 구조에 맞게 `asChild` 로 바꾼다   |
| `Card.Description` | 보조 설명                                                        |
| `Card.Body`        | 본문                                                             |
| `Card.Footer`      | 버튼 등 동작                                                     |
| `Card.Link`        | `interactive` 카드의 대표 링크. 클릭 영역이 카드 전체로 넓어진다 |

### 누를 수 있는 카드

카드 전체를 누르게 하고 싶을 때 **카드를 클릭 가능한 `div` 로 만들지 않는다.** 대신 제목 안에 `Card.Link` 를 하나 두고 `interactive` 를 켠다.
링크의 클릭 영역이 카드 전체로 넓어지지만, 스크린리더와 키보드에게는 평범한 링크 하나로 보인다. 카드 안의 다른 버튼은 링크 위로 올라와 따로 동작한다.

## 접근성

### 키보드

| 키      | 동작                                                    |
| ------- | ------------------------------------------------------- |
| `Tab`   | 대표 링크로 이동한 뒤, 카드 안의 다른 버튼으로 이동한다 |
| `Enter` | 대표 링크를 연다                                        |

### 스크린리더

- 카드 자체에는 역할이 없다. 제목(`<h3>`)이 있어 제목 단위 이동으로 카드를 훑어볼 수 있다.
- `interactive` 카드에서 링크의 이름은 **제목만**이다. 카드 전체 텍스트를 링크로 감싸면 스크린리더가 링크를 읽을 때 본문까지 길게 읽어버린다.
- 포커스 링은 링크가 아니라 카드 전체에 그려져 클릭 영역과 일치한다 (`:has()` 를 지원하지 않는 브라우저에서는 링크 주변에 그린다).

### 사용자 설정

- Windows 고대비 모드에서 카드 테두리가 시스템 텍스트 색으로 보인다.
- `prefers-reduced-motion` 이면 hover 전환 효과를 끈다.
