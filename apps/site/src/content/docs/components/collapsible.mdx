버튼 하나로 **영역 하나를 접고 펴는** 컴포넌트. "상세 보기", "고급 설정"처럼 평소에는 숨겨 두어도 되는 내용에 쓴다.

## 사용법

```tsx
import { Collapsible } from '@hoon-ds/react';

<Collapsible.Root>
  <Collapsible.Trigger>상세 보기</Collapsible.Trigger>
  <Collapsible.Content>{/* 접히는 내용 */}</Collapsible.Content>
</Collapsible.Root>;
```

| 부품      | 역할                                                                             |
| --------- | -------------------------------------------------------------------------------- |
| `Root`    | 열림 상태. `open`/`onOpenChange`(제어) 또는 `defaultOpen`(비제어), `disabled`    |
| `Trigger` | 여닫는 버튼. 그대로 쓰면 텍스트 버튼 모양, `asChild` 로 Button 을 감쌀 수도 있다 |
| `Content` | 접히는 내용. 높이 애니메이션과 함께 열리고 닫힌다                                |

### Collapsible 과 Accordion

|        | Collapsible              | [Accordion](/components/accordion/)          |
| ------ | ------------------------ | -------------------------------------------- |
| 개수   | 영역 하나                | 같은 모양의 항목 여러 개                     |
| 구조   | 자유롭게 배치            | 제목(heading) + 버튼 + 패널로 고정           |
| 키보드 | Tab, Enter, Space        | 여기에 더해 항목 사이를 이동하는 규칙이 있다 |
| 예     | "상세 보기", "고급 설정" | FAQ, 설정 카테고리 목록                      |

## API

### Content

`forceMount` 를 주면 닫혀 있어도 DOM 에 남는다 (브라우저의 페이지 내 검색에 걸려야 할 때 등). 이때도 화면과 보조기기에서는 숨겨진다.
그 외는 [Radix Collapsible.Content](https://www.radix-ui.com/primitives/docs/components/collapsible#content) 를 따른다.

### 그 외 부품

| 부품      | 설명                                                                                                 |
| --------- | ---------------------------------------------------------------------------------------------------- |
| `Root`    | [Radix Collapsible.Root](https://www.radix-ui.com/primitives/docs/components/collapsible#root)       |
| `Trigger` | [Radix Collapsible.Trigger](https://www.radix-ui.com/primitives/docs/components/collapsible#trigger) |

## 접근성

[WAI-ARIA APG Disclosure 패턴](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/)을 따른다.

### 키보드

| 키                | 동작                   |
| ----------------- | ---------------------- |
| `Tab`             | 트리거로 포커스 이동   |
| `Enter` / `Space` | 영역을 펼치거나 접는다 |

### 스크린리더

- 트리거는 `aria-expanded` 로 열림 상태를, `aria-controls` 로 내용 영역을 알린다.
- 트리거 문구는 무엇을 펼치는지 알 수 있게 쓴다. 열림 상태는 `aria-expanded` 가 전하므로 "펼치기/접기"처럼 문구를 바꿀 필요는 없다.
- 닫힌 내용은 보조기기에서도 숨겨진다.

### 사용자 설정

- `prefers-reduced-motion` 이면 높이 애니메이션 없이 바로 열고 닫는다. 화살표 아이콘 회전도 멈춘다.
- Windows 고대비 모드에서 트리거는 시스템 링크 색으로 보인다.
