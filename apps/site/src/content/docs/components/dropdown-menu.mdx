버튼을 눌러 여는 **동작 목록**. 편집·복제·삭제처럼 공간이 부족해 모두 펼쳐 둘 수 없는 동작을 모은다.
[WAI-ARIA Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) 패턴을 따른다.

<Preview code={basicCode} minHeight="20rem">
  <Basic client:idle />
</Preview>

## 사용법

```tsx
import { Button, DropdownMenu } from '@hoon-ds/react';

<DropdownMenu.Root>
  <DropdownMenu.Trigger asChild>
    <Button variant="secondary">옵션</Button>
  </DropdownMenu.Trigger>
  <DropdownMenu.Content>
    <DropdownMenu.Item onSelect={edit}>편집</DropdownMenu.Item>
    <DropdownMenu.Separator />
    <DropdownMenu.Item variant="danger" onSelect={remove}>
      삭제
    </DropdownMenu.Item>
  </DropdownMenu.Content>
</DropdownMenu.Root>;
```

| 부품                                        | 역할                                                            |
| ------------------------------------------- | --------------------------------------------------------------- |
| `Root`                                      | 열림 상태. 기본 `modal`: 열린 동안 바깥을 보조기기에서 숨긴다   |
| `Trigger`                                   | 여는 버튼. `asChild` 로 Button·IconButton 을 감싼다             |
| `Content`                                   | 메뉴. `side`·`align` 으로 위치, 화면 끝에서는 자동으로 뒤집힌다 |
| `Item`                                      | 동작. `onSelect` 로 실행, `variant="danger"`, `inset`           |
| `CheckboxItem` · `RadioGroup` · `RadioItem` | 켜고 끄는 설정, 하나만 고르는 설정                              |
| `Label` · `Group` · `Separator`             | 묶음 제목, 묶음, 구분선                                         |
| `Sub` · `SubTrigger` · `SubContent`         | 하위 메뉴                                                       |
| `Shortcut`                                  | 단축키 표시(시각 전용)                                          |

## 메뉴 · Select · 내비게이션 고르기

| 하려는 일                        | 컴포넌트                                   |
| -------------------------------- | ------------------------------------------ |
| 동작 실행 (편집, 삭제, 내보내기) | **DropdownMenu**                           |
| 폼 값 고르기 (국가, 과일)        | [Select](/components/select/)              |
| 다른 페이지로 이동               | 링크 목록 (`<nav>` + `<a>`): 메뉴가 아니다 |

ARIA `menu` 는 데스크톱 앱 메뉴를 흉내 내는 역할이라, 링크를 넣으면 스크린리더가 "메뉴 항목"으로 읽고 링크 기능(새 탭 열기 등)을 기대하기 어렵다.
사이트 내비게이션 드롭다운은 disclosure 패턴(버튼 + 링크 목록)으로 만든다.

## 접근성

### 키보드

| 키                      | 동작                                                      |
| ----------------------- | --------------------------------------------------------- |
| `Enter` / `Space` / `↓` | 트리거에서 메뉴 열기, 첫 항목에 포커스                    |
| `↓` / `↑`               | 다음 / 이전 항목 (비활성 항목은 건너뜀)                   |
| `Home` / `End`          | 첫 / 마지막 항목                                          |
| `Enter` / `Space`       | 항목 실행 후 닫기, 포커스는 트리거로 (체크·라디오는 토글) |
| `→` / `←`               | 하위 메뉴 열기 / 닫기                                     |
| `Esc`                   | 닫기, 포커스는 트리거로                                   |
| 글자 입력               | 일치하는 항목으로 이동                                    |

### 스크린리더

- 트리거는 `aria-haspopup="menu"` + `aria-expanded`, 메뉴는 `role="menu"`.
- 항목은 `menuitem` / `menuitemcheckbox` / `menuitemradio` + `aria-checked`, 비활성은 `aria-disabled`.
- `Shortcut` 은 시각적 힌트라 `aria-hidden` 이다. 단축키를 보조기기에 알리려면 Item 에 `aria-keyshortcuts="Meta+E"` 를 준다.
- 아이콘은 장식이므로 `aria-hidden` 으로 둔다. 항목의 이름은 텍스트에서 나온다.

### 사용자 설정

- `prefers-reduced-motion` 이면 열림 애니메이션을 끈다.
- Windows 고대비 모드에서 강조 항목이 `Highlight` 시스템 색으로 보인다.
- RTL 레이아웃에서 하위 메뉴 화살표가 뒤집힌다.
