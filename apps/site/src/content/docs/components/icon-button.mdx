아이콘만 있는 정사각형 버튼. 닫기, 설정, 더보기처럼 **아이콘만으로 널리 통하는 동작**에 쓴다.
[Button](/components/button/) 의 모든 기능(`loading`, `focusableWhenDisabled` …)을 그대로 가진다.

<Preview code={basicCode}>
  <Basic />
</Preview>

## 사용법

```tsx
import { IconButton } from '@hoon-ds/react';

<IconButton aria-label="닫기" onClick={close}>
  <XIcon />
</IconButton>;
```

`aria-label` 은 **타입 단계에서 필수**다. 빠뜨리면 컴파일 오류가 난다.

`asChild` 는 지원하지 않는다. 아이콘만 있는 링크가 필요하면 [Button](/components/button/) 의 `asChild` 와 `aria-label` 을 쓴다.

## 접근성

### 키보드

| 키                | 동작        |
| ----------------- | ----------- |
| `Tab`             | 포커스 이동 |
| `Enter` / `Space` | 실행        |

### 스크린리더

- 접근 가능한 이름은 `aria-label` 하나로 정해진다. 아이콘은 자동으로 `aria-hidden` 처리된다.
- 이름은 **동작**을 쓴다: "닫기", "삭제" (아이콘 모양인 "X", "휴지통" 이 아니다).
- 시각 사용자도 의미를 알 수 있게 Tooltip 으로 같은 문구를 보여주는 것을 권장한다.

### 사용자 설정

Button 과 같다: 고대비 모드 테두리, 동작 줄이기, 터치 hover 처리.
