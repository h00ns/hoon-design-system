다른 페이지나 위치로 **이동**하는 텍스트 링크. 무언가를 실행한다면 [Button](/components/button/) 을 쓴다.

<Preview code={basicCode}>
  <Basic client:visible />
</Preview>

## 사용법

```tsx
import { Link } from '@hoon-ds/react';

<Link href="/docs">문서</Link>;

// 라우터 링크
<Link asChild>
  <NextLink href="/docs">문서</NextLink>
</Link>;
```

## 예시

### 외부 링크

`external` 을 주면 새 창으로 열고 `rel="noopener noreferrer"` 를 붙인다. 아이콘과 함께 스크린리더에는 "(새 창)" 을 덧붙여, 맥락이 바뀐다는 것을 미리 알린다 (WCAG 3.2.5). `target="_blank"` 를 직접 줘도 같다.

</Preview>

### Variant · 밑줄

문장 속 링크는 색만으로 구분하면 안 되므로 기본은 **항상 밑줄**이다. `underline="hover"` 는 내비게이션처럼 링크임이 분명한 곳에서만 쓴다.

## 접근성

### 키보드

| 키      | 동작            |
| ------- | --------------- |
| `Tab`   | 링크로 이동한다 |
| `Enter` | 링크를 연다     |

### 스크린리더

- 네이티브 `<a href>` 라 역할과 방문 여부를 브라우저가 전달한다.
- 링크 문구만 듣고도 목적지를 알 수 있게 쓴다. 스크린리더 사용자는 링크 목록만 따로 훑어보기도 한다.
- 새 창 안내 문구는 `newTabLabel` 로 바꿀 수 있다.

### 사용자 설정

- 기본 밑줄 덕분에 색을 구분하기 어려운 사용자도 링크를 찾을 수 있다 (WCAG 1.4.1).
- Windows 고대비 모드에서 시스템 링크 색으로 보인다.
