여러 선택지 중 **정확히 하나**를 고른다. 선택지가 2~6개이고 모두 한눈에 비교해야 할 때 쓴다.
선택지가 많으면 [Select](/components/select/), 여러 개를 고르면 [Checkbox](/components/checkbox/).

<Preview code={basicCode}>
  <Basic client:visible />
</Preview>

## 사용법

```tsx
import { Field, RadioGroup } from '@hoon-ds/react';
```

```tsx
<Field.Root>
  <Field.Label>배송 방법</Field.Label>
  <RadioGroup.Root name="shipping" defaultValue="normal">
    <RadioGroup.Item value="normal">일반 배송</RadioGroup.Item>
    <RadioGroup.Item value="fast" description="내일 도착">
      빠른 배송
    </RadioGroup.Item>
  </RadioGroup.Root>
</Field.Root>
```

| 부품              | 역할                                                                               |
| ----------------- | ---------------------------------------------------------------------------------- |
| `RadioGroup.Root` | `role="radiogroup"`. `value`/`defaultValue`/`onValueChange`, `name`, `orientation` |
| `RadioGroup.Item` | `role="radio"`. `children` 은 레이블, `description` 은 보조 설명                   |

## 예시

## 접근성

### 키보드

| 키                  | 동작                                               |
| ------------------- | -------------------------------------------------- |
| `Tab`               | 그룹으로 포커스 (선택된 항목, 없으면 첫 항목)      |
| `↓` / `→`           | 다음 항목으로 이동하며 선택 (끝에서 처음으로 순환) |
| `↑` / `←`           | 이전 항목으로 이동하며 선택                        |
| `Space`             | 포커스된 항목 선택 (선택된 게 없을 때)             |
| `Tab` (그룹 안에서) | 그룹을 빠져나감: 그룹 전체가 탭 정지 하나          |

비활성 항목은 화살표 이동에서 건너뛴다.

### 스크린리더

- `role="radiogroup"` 안의 `role="radio"` + `aria-checked` 로 "3개 중 2번째, 선택됨"처럼 읽힌다.
- 그룹 이름은 Field.Label(`aria-labelledby`) 또는 `aria-label` 로 반드시 준다.
- 필수·오류·설명은 그룹 단위로 `aria-required`·`aria-invalid`·`aria-describedby` 가 걸린다.
- `<form>` 안에서는 숨겨진 네이티브 라디오로 `name`=`value` 가 제출된다.

### 사용자 설정

- 라디오 원은 18px 이지만 누를 수 있는 영역은 26px 이상이고, 레이블을 눌러도 선택된다.
- 선택 상태는 색뿐 아니라 가운데 점 **모양**으로 구분된다.
- Windows 고대비 모드에서 선택 상태가 시스템 강조색으로 보인다.
