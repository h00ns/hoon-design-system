정해진 범위 안에서 **값을 끌어서 고르는** 컨트롤. 음량, 밝기처럼 정확한 숫자보다 상대적인 크기가 중요할 때 쓴다.
값 배열에 숫자가 2개면 구간을 고르는 범위 슬라이더가 된다.
[WAI-ARIA Slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/) 패턴을 따른다.

  <Basic client:visible />
</Preview>

## 사용법

```tsx
import { Field, Slider } from '@hoon-ds/react';

<Field.Root>
  <Field.Label>음량</Field.Label>
  <Slider defaultValue={[40]} getValueText={(v) => `${v}%`} />
</Field.Root>;
```

`value`·`defaultValue` 는 **항상 배열**이다 (`[40]`, `[20, 80]`).

## 접근성

### 키보드

| 키                        | 동작                                    |
| ------------------------- | --------------------------------------- |
| `Tab`                     | 손잡이로 이동 (범위면 손잡이마다 한 번) |
| `ArrowRight` / `ArrowUp`  | `step` 만큼 증가                        |
| `ArrowLeft` / `ArrowDown` | `step` 만큼 감소                        |
| `PageUp` / `PageDown`     | 크게(10단계) 증가·감소                  |
| `Shift` + 화살표          | 크게(10단계) 증가·감소                  |
| `Home` / `End`            | 최솟값 / 최댓값                         |

### 스크린리더

- 손잡이는 `role="slider"` 와 `aria-valuenow`·`aria-valuemin`·`aria-valuemax` 를 가진다.
- **단위가 있으면 `getValueText` 를 꼭 준다.** 없으면 "30000" 처럼 숫자만 읽힌다. 주면 "30,000원" 으로 읽힌다 (`aria-valuetext`).
- Radix 는 범위 손잡이에 영어 기본 이름("Minimum", "Maximum")을 붙이는데, 이 컴포넌트는 항상 한국어 이름으로 덮어쓴다. `thumbLabels` 로 바꿀 수 있다.
- Field 의 레이블·설명·오류가 모든 손잡이에 연결된다.

### 사용자 설정

- 트랙은 옅은 배경 위에 컨트롤 경계색 테두리를 둘러 3:1 대비를 맞춘다 (WCAG 1.4.11).
- 보이는 손잡이는 20px 이지만 누를 수 있는 영역은 24px 이상이다 (WCAG 2.5.8).
- Windows 고대비 모드에서 채워진 구간은 시스템 강조색으로 보인다.
- `prefers-reduced-motion` 에서 손잡이 확대 효과를 끈다.
