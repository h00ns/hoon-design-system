**진행 중**임을 알리는 표시. 끝나는 시점을 알 수 없는 짧은 대기에 쓴다.
버튼 안의 로딩은 Spinner 를 직접 넣지 말고 [Button](/components/button/) 의 `loading` 을 쓴다.

<Preview code={basicCode}>
  <Basic />
</Preview>

## 사용법

```tsx
import { Spinner } from '@hoon-ds/react';

<Spinner label="주문 내역을 불러오는 중" />;
```

## 예시

### 크기

`sm` 16px · `md` 24px · `lg` 36px. 색은 `accent-solid` 이며 `color` 로 바꿀 수 있다.

<Preview code={sizesCode}>
  <Sizes />
</Preview>

### 영역 로딩

로딩 중인 영역에 `aria-busy="true"` 를 걸고, `label` 은 **무엇을** 불러오는지 구체적으로 쓴다.

## 접근성

### 스크린리더

- `role="status"` 라서 스크린리더가 `label` 을 정중하게(polite) 읽는다. 기본값은 "불러오는 중".
- 회전하는 원은 `aria-hidden` 이라 읽히지 않는다.
- 로딩이 **끝났다는 사실**도 알려야 한다면 결과 영역의 제목으로 포커스를 옮기거나 live region 으로 알린다.

### 사용자 설정

- `prefers-reduced-motion` 이면 멈추지 않고 **느리게** 돈다. 멈춘 스피너는 "멈췄다"로 오해된다.
- Windows 고대비 모드에서 시스템 텍스트 색으로 보인다.
