**켜고 끄는 버튼**(`Toggle`)과, 관련된 토글을 한 줄로 묶는 `ToggleGroup`.
보기 방식 전환, 글자 서식, 기간 선택처럼 **누르는 즉시 화면이 바뀌는** 도구에 쓴다.

<Preview code={singleCode}>
  <Single client:visible />
</Preview>

## 사용법

```tsx
import { Toggle, ToggleGroup } from '@hoon-ds/react';

<ToggleGroup.Root type="single" aria-label="정렬" defaultValue="left">
  <ToggleGroup.Item value="left">왼쪽</ToggleGroup.Item>
  <ToggleGroup.Item value="right">오른쪽</ToggleGroup.Item>
</ToggleGroup.Root>;
```

- `type="single"`: 하나만 고른다. 스크린리더에는 `radiogroup` 과 `radio` 로 전달된다.
- `type="multiple"`: 여러 개를 켠다. `toolbar` 와 `aria-pressed` 버튼으로 전달된다.

## 접근성

### 키보드

| 키                         | 동작                                                 |
| -------------------------- | ---------------------------------------------------- |
| `Tab`                      | 그룹으로 한 번만 들어온다 (선택된 항목 또는 첫 항목) |
| `ArrowRight` / `ArrowDown` | 다음 항목으로 이동 (비활성 항목은 건너뜀)            |
| `ArrowLeft` / `ArrowUp`    | 이전 항목으로 이동                                   |
| `Home` / `End`             | 첫 항목 / 마지막 항목                                |
| `Space` / `Enter`          | 항목을 켜거나 끈다                                   |

### 스크린리더

- 그룹에는 `aria-label` 이나 Field.Label 로 **이름을 꼭 준다.** "정렬", "글자 서식" 처럼 묶음의 목적을 쓴다.
- 아이콘은 자동으로 `aria-hidden` 처리되고 이름은 `aria-label` 이나 텍스트로 정해진다.
- `type="single"` 은 `aria-checked`, `type="multiple"` 과 단독 Toggle 은 `aria-pressed` 로 상태를 전달한다.

### 사용자 설정

- 켜짐 상태는 배경색만이 아니라 **테두리 굵기와 글자 굵기**도 함께 바뀐다. 색을 구분하기 어려워도 알 수 있다.
- Windows 고대비 모드에서 켜진 항목은 시스템 강조색으로 보인다.
- `prefers-reduced-motion` 에서 색 전환 애니메이션을 끈다.
