화면에는 보이지 않지만 **스크린리더는 읽는** 콘텐츠. 시각적으로는 맥락이 분명하지만 텍스트로는 부족한 정보를 보충할 때 쓴다.

<Preview code={basicCode}>
  <Basic />
</Preview>

## 사용법

```tsx
import { VisuallyHidden } from '@hoon-ds/react';

<p>
  장바구니 3<VisuallyHidden>개 상품</VisuallyHidden>
</p>;
```

## 예시

### 숫자에 맥락 더하기

시각적으로는 아이콘이나 위치로 의미가 전달되지만, 스크린리더는 "3"만 읽게 되는 경우.

`focusable` 이면 키보드 포커스를 받을 때 화면에 드러난다. 반복되는 내비게이션을 건너뛰는 링크에 쓴다 (WCAG 2.4.1).

## 접근성

### 스크린리더

- `display: none` 이나 `visibility: hidden` 과 달리 **접근성 트리에 남는다.**
- `clip-path` 기법으로 숨겨서 레이아웃에 영향을 주지 않는다.
- React 를 쓰지 않는 환경에서는 `.hds-visually-hidden` 클래스만 붙여도 같은 효과다.
