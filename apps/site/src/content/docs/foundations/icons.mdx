`@hoon-ds/icons` 는 UI 에 자주 쓰는 아이콘을 골라 담은 패키지다. React 컴포넌트와 원본 SVG 를 함께 제공하고, 쓴 아이콘만 번들에 들어간다.

```sh
pnpm add @hoon-ds/icons
```

## 전체 아이콘

<IconGallery client:visible />

## 사용법

```tsx
import { SearchIcon, TrashIcon, WarningIcon } from '@hoon-ds/icons';

// 장식: 옆에 글자가 있으면 숨긴다 (기본값)
<Button><TrashIcon /> 삭제</Button>

// 아이콘만 있는 버튼: 이름은 아이콘이 아니라 버튼에 붙인다
<IconButton aria-label="검색"><SearchIcon /></IconButton>

// 아이콘 자체가 정보를 전할 때만 title
<WarningIcon title="경고" weight="fill" />
```

## 접근성

- **기본은 장식 아이콘**이다. `aria-hidden="true"`, `focusable="false"` 가 붙어 스크린리더가 읽지 않는다. 대부분의 아이콘은 옆에 글자가 있어 이게 맞다.
- 아이콘만으로 의미를 전할 때는 `title` 을 준다. `role="img"` 와 `<title>` 로 이름을 가진다.
- 버튼·링크 안의 아이콘에는 `title` 을 주지 않는다. 이름은 버튼(`aria-label`)에 붙인다. 아이콘에도 이름을 주면 두 번 읽힌다.
- 색만으로 상태를 구분하지 않는다. 오류 아이콘 옆에는 오류 문구를 함께 둔다.

## 크기와 굵기

- 크기 기본값은 `1em` 이라 주변 글자 크기를 그대로 따른다. 버튼·입력 안에서는 따로 정하지 않아도 된다.
- 색은 `currentColor` 라 글자색을 따른다. 색을 바꾸려면 부모의 `color` 를 바꾼다.
- 굵기는 `regular` 가 기본이다. 16px 이하로 작게 쓰거나 강조할 때는 `bold`, 켜짐 상태(즐겨찾기 등)는 `fill` 을 쓴다.

| prop       | 타입                            | 기본값           | 설명                                     |
| ---------- | ------------------------------- | ---------------- | ---------------------------------------- |
| `size`     | `number \| string`              | `'1em'`          | 가로·세로 크기                           |
| `weight`   | `'regular' \| 'bold' \| 'fill'` | `'regular'`      | 획 굵기                                  |
| `title`    | `string`                        | -                | 접근 가능한 이름. 없으면 장식으로 숨긴다 |
| `color`    | `string`                        | `'currentColor'` | 채우기 색                                |
| `mirrored` | `boolean`                       | `false`          | RTL 문서에서 좌우 반전                   |

## React 없이

원본 SVG 를 그대로 쓸 수 있다. 굵기는 파일 이름 뒤에 `-bold`, `-fill` 을 붙인다.

```html
<img src="node_modules/@hoon-ds/icons/svg/search.svg" alt="" width="20" height="20" />
```

검색 UI 를 만들 때 쓰는 이름·분류·검색어는 `@hoon-ds/icons/meta` 에서 가져온다.
