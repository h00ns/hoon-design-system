움직임은 **상태 변화를 이해시키는 데만** 쓴다. 장식용 애니메이션은 두지 않는다.

<MotionTokens />

## 사용 기준

| 토큰                | 용도                                            |
| ------------------- | ----------------------------------------------- |
| `duration-fast`     | hover, 색 변화, 작은 상태 전환                  |
| `duration-normal`   | Popover·Menu 열기, Accordion 펼치기             |
| `duration-slow`     | Dialog·Toast 등장                               |
| `easing-standard`   | 대부분의 전환                                   |
| `easing-emphasized` | 등장할 때 살짝 튀는 느낌이 필요한 경우 (드물게) |

## 동작 줄이기 (prefers-reduced-motion)

전정기관 장애가 있는 사용자에게 움직임은 어지럼증을 일으킬 수 있다 (WCAG 2.3.3).
모든 컴포넌트는 `prefers-reduced-motion: reduce` 에서:

- 이동·확대 애니메이션을 끄거나 투명도 전환으로 바꾼다.
- **의미가 있는 움직임**(로딩 스피너)은 멈추지 않고 느리게만 돌린다. 멈추면 "멈췄다"로 오해할 수 있다.

macOS: 시스템 설정 → 손쉬운 사용 → 디스플레이 → **동작 줄이기** 로 확인할 수 있다.
