## 왜 hoon-design-system 인가

<CardGrid>
  <Card title="키보드 우선" icon="seti:pipeline">
    모든 컴포넌트가 WAI-ARIA APG 패턴의 키보드 동작을 따른다. 포커스는 항상 보이고, 오버레이가
    닫히면 트리거로 돌아간다.
  </Card>
  <Card title="스크린리더 친화" icon="comment">
    역할·이름·상태를 정확히 노출한다. 아이콘 버튼의 `aria-label` 처럼 빠뜨리기 쉬운 것은 타입
    단계에서 필수로 만들었다.
  </Card>
  <Card title="대비를 테스트로 보장" icon="approve-check">
    모든 색 조합의 WCAG 대비를 빌드 때마다 검증한다. 기준에 못 미치는 토큰은 배포되지 않는다.
  </Card>
  <Card title="사용자 설정 존중" icon="setting">
    다크 모드, 동작 줄이기, Windows 고대비, 200% 확대에서도 깨지지 않는다.
  </Card>
</CardGrid>
